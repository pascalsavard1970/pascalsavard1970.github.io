# Home Assistant — installation personnelle

Cette page accompagne une instance Home Assistant privée, utilisée pour la domotique d'une seule résidence au Québec.

L'application n'est pas distribuée publiquement et ne compte qu'un seul utilisateur : son propriétaire. Elle sert uniquement à relier des appareils domotiques personnels (thermostats, capteurs, caméras) à une installation Home Assistant hébergée localement.
